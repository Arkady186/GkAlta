# ГК Альта — сайт ЖК в Краснодоне

Статический сайт: полноэкранные сцены с видеопереходами, 3D-генплан, выбор квартиры (секция → этаж → квартира), фото-прогулка и 3D-прогулка по квартире.

Запуск: открыть `index.html` или включить GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
